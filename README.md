# 🚀 TechLearn Placement Sprint

A full-stack MERN application built for the TechLearn Internship Assignment. Users can register, log in securely, choose between a Free or Paid plan, simulate a payment, and access dashboards based on their subscription.

## 🔗 Live Demo

**Frontend:** https://techlearn-placement-sprint.vercel.app/

**Backend:** https://techlearn-backend-308g.onrender.com

## ✨ Features

- User Registration & Login
- JWT Authentication
- Password Hashing (bcrypt)
- Free & Paid Plans
- Simulated Payment Flow
- Role-Based Dashboards
- MongoDB Atlas Database
- Responsive UI

## 🛠 Tech Stack

**Frontend**
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs

**Deployment**
- Vercel
- Render

## ⚙️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file inside `backend`:

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_SECRET
```
